# Реалізація структури даних «Бінарне дерево»

Програма для практичної роботи №8: реалізація двійкового дерева пошуку (Binary Search Tree) на базі зв'язаних вузлів із підтримкою рекурсивних операцій.

## Що реалізовано

* **Вузлова архітектура:** клас `Node` (значення `value`, покажчики `left` та `right`) і клас `BinarySearchTree` із покажчиком на корінь `root`.
* **Основні операції з деревом:**
  1. `insert(value)` — вставка елемента за правилами BST (менші — ліворуч, більші або рівні — праворуч)
  2. `delete(value)` — видалення вузла з коректною заміною (обробка випадків: без нащадків, 1 нащадок, 2 нащадки через in-order successor)
  3. `contains(value)` — швидкий логарифмічний пошук елемента
  4. `to_list()` — симетричний обхід (in-order traversal) для виведення всіх елементів у порядку зростання
  5. `find_min()` / `find_max()` — знаходження найменшого та найбільшого значень
  6. `count()` — рекурсивний підрахунок загальної кількості вузлів
